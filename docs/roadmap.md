# Build Roadmap (MVP → V1)

## Phase 1 — Foundation (2–3 weeks)

- Multi-tenant auth, org/client/user model.
- Connect 1 platform (start with **Meta** — covers FB + IG in one API).
- Basic composer + manual publish (no scheduling yet).

## Phase 2 — Scheduling & Queue (2 weeks)

- BullMQ scheduling, content calendar UI.
- Approval workflow: draft → approve → publish.

## Phase 3 — Unified Inbox (2–3 weeks)

- Comment/DM ingestion (webhook + polling fallback).
- Reply sending, assignment, canned responses.

## Phase 4 — Second/Third Platform + AI (2 weeks)

- Add X and LinkedIn adapters.
- AI-drafted reply suggestions (Claude Haiku) + sentiment tagging.

## Phase 5 — Billing & White-Label (1–2 weeks)

- Stripe subscriptions, client portal branding, PDF reports.

## Phase 6 — Analytics Rollups & Polish

- Cross-client dashboards, scheduled report emails, SLA alerting.
